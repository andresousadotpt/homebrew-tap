# homebrew-tap

Personal Homebrew tap for macOS apps.

## Install macdaily

```bash
brew tap andresousadotpt/tap
brew install --cask macdaily
```

If macOS blocks the app on first launch, see the [build-from-source instructions](https://github.com/andresousadotpt/macdaily#option-a--build-from-source-recommended) in the macdaily README.

## Apps

| Cask | Description |
| ---- | ----------- |
| [macdaily](https://github.com/andresousadotpt/macdaily) | Daily markdown notes |
